**Marqoom (مرقوم)** brings together ongoing work on Quranic data standards. These docs explain the standards, the problems they address, and how projects can put them into practice.

The aim is to reduce the decisions developers have to repeat when working with Quranic data. When sources use different names, numbering conventions, and data formats, every application has to reconcile them. Shared rules and clear examples make it easier to use data across projects.

## Why a shared standard [#integration-diff]

Say you're building an app that plays a recitation alongside the text: the recitations come from MP3 Quran and the ayah timings from Munajjam. If every project names its data its own way, you write an adapter for each one to translate its names into yours. And it doesn't stop with you: every other project writes its own adapters too, so the same work is repeated everywhere, and it grows with every project that joins.

If we agree on the names, each project learns them once and can then read everyone's data.
