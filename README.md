# Marqoom | مرقوم

Marqoom documents shared standards for Quranic data: the names, formats and rules that projects keep deciding on their own. The first published standard is Quranic terminology (v0.1). Text, audio, segmentation and timing come later.

مرقوم يوثّق معايير مشتركة للبيانات القرآنية: الأسماء والصيغ والقواعد التي يقرّرها كل مشروع وحده اليوم. أول معيار منشور هو معيار المصطلحات القرآنية (الإصدار 0.1).

**Read the standards:** [marqoom-specs.com](https://marqoom-specs.com/docs) · [بالعربية](https://marqoom-specs.com/ar/docs)

## Suggest a change

On any terms page, turn on **Suggest edits**, point at the paragraph, and the button opens an issue here with the page, the heading and the current text filled in. You can also [open one directly](https://github.com/marqoom-specs/specs/issues/new?template=edit.yml).

Problems with the lint tool go to [quranic-terminology-lint](https://github.com/marqoom-specs/quranic-terminology-lint).

## What's here

- `content/docs/`: the pages. English at the top level, Arabic under `ar/`.
- `content/docs/{,ar/}terms/`: the terminology standard, its dictionary and registries. These `.md` files are generated by `scripts/import-terminology.py` from the archive in `public/sources/`; change that source and rerun the script rather than editing them by hand.
- `components/`, `app/`, `lib/`: the site, built with [Fumadocs](https://fumadocs.dev) and Next.js, deployed on Cloudflare Workers.

## Run it locally

Use Node.js 22 or later:

```sh
npm ci
npm run dev -- --hostname localhost
```

Open [English](http://localhost:3000/docs) or [Arabic](http://localhost:3000/ar/docs).

Before sending a change:

```sh
npm run check:content
npm run check:reading
npm run build
npm start -- --hostname localhost
# In another terminal, with the production server running:
npm run check:site
```

`check:content` confirms the generated pages still match the archive. `check:reading` checks the reading layout and the figures' data. `check:site` checks every page, anchor, redirect and the search in both languages against a running server. `scripts/build-visual-lab-data.py` needs PyYAML.

See [CLAUDE.md](./CLAUDE.md) for the full project guide.
