# Monolith

Selected direction D from the Foundation exploration. The connected crown and broad feet represent a shared foundation; the slightly asymmetric top makes the silhouette distinctive.

- `identity.png`: approved English/Arabic and light/dark presentation.
- `../../../public/brand/monolith.png`: 144px transparent 3D mark used in navigation.
- `../../../app/icon.png`: 64px PNG favicon, downsampled from the same original asset.
- `mark.svg`: flat alternative.
- `monolith.png`: original transparent 3D asset.

Both names use the site's existing Thmanyah Sans. The mark retains its orientation in RTL. The user chose the 3D mark for navigation and the favicon, with no logo image in the hero.

The 3D asset was isolated from the approved presentation using the built-in image generation tool. Its exact prompt is in `asset-prompt.txt`.
